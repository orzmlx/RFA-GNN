\chapter{Full Gene Space Supplementary Results}
\label{app:full_gene_space_results}

\noindent In addition to the main benchmark on the 978 landmark genes, a small supplementary run was also carried out in the full gene space with 12,328 genes. This experiment is included only as supporting information. It should not be compared directly with the main results in the thesis. The reason is that the full gene space run used a different practical configuration under tighter memory and runtime constraints. In particular, it did not use the uncertainty output and it did not use the counterfactual drug loss. The reported values should therefore be read as a limited point prediction check in the larger gene space rather than as an alternative main benchmark.

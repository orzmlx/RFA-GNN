\chapter{Methodology}

\section{Problem formulation}
This thesis studies drug perturbation prediction. Let $G$ be the number of genes in the selected gene set. For one sample, the matched control profile is $x_{\mathrm{ctl}} \in \mathbb{R}^{G}$ and the treated profile is $x_{\mathrm{trt}} \in \mathbb{R}^{G}$. The supervised target is
\begin{equation}
y = x_{\mathrm{trt}} - x_{\mathrm{ctl}} \in \mathbb{R}^{G}.
\end{equation}
The model output is a predicted response vector $\hat{y} \in \mathbb{R}^{G}$. All models in this thesis use the same target.

\noindent The main drug input is a target vector aligned to the same gene order. It is written as $x_{\mathrm{drug}} \in \mathbb{R}^{G}$. Its entries are binary. An entry is one when the corresponding gene is an annotated target of the drug. In some model variants, an extra fingerprint vector can also be used. The current main benchmark results in this thesis use the target based drug vector.

\noindent For a mini batch of size $B$, the control input has shape $X_{\mathrm{ctl}} \in \mathbb{R}^{B \times G}$, the drug input has shape $X_{\mathrm{drug}} \in \mathbb{R}^{B \times G}$, the target has shape $Y \in \mathbb{R}^{B \times G}$, and the model prediction has shape $\hat{Y} \in \mathbb{R}^{B \times G}$.

\section{Benchmark model}
\subsection{Architecture}
Figure~\ref{fig:base_model_structure} shows the benchmark model. The benchmark follows the DeepCOP style fully connected design~\cite{woo2020deepcop}. It does not use a biological interaction graph.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.95\linewidth]{figures/base_model_structure.png}
    \caption{Structure of the benchmark model. Control gene expression and drug features are concatenated and passed through a feed forward network to predict the response vector.}
    \label{fig:base_model_structure}
\end{figure}

\noindent In the current benchmark setting, the input contains the control profile $x_{\mathrm{ctl}} \in \mathbb{R}^{G}$ and the target based drug vector $x_{\mathrm{drug}} \in \mathbb{R}^{G}$. The concatenated input is
\begin{equation}
z = [x_{\mathrm{ctl}} \Vert x_{\mathrm{drug}}] \in \mathbb{R}^{2G}.
\end{equation}
For a mini batch, the same input is written as $Z \in \mathbb{R}^{B \times 2G}$. The model then applies two fully connected blocks. Each block uses a dense layer, batch normalization, ReLU, and dropout. The current implementation uses a hidden width of 1024. This means that the hidden representation after each block has shape $\mathbb{R}^{B \times 1024}$. A final linear layer maps the hidden vector to the output
\begin{equation}
\hat{y} \in \mathbb{R}^{G}.
\end{equation}
At batch level, the final output has shape $\hat{Y} \in \mathbb{R}^{B \times G}$.

\subsection{Loss function}
The benchmark model is trained with mean squared error. In the current implementation, the training target is residualized by subtracting a cell specific mean response estimated from the training set. If this residual target is written as $y^{\prime} \in \mathbb{R}^{G}$, the training loss is
\begin{equation}
\mathcal{L}_{\mathrm{base}}=\frac{1}{BG}\sum_{i=1}^{B}\sum_{g=1}^{G}\left(y^{\prime}_{ig}-\hat{y}_{ig}\right)^{2},
\end{equation}
where $B$ is the mini batch size.

\subsection{Optimization}
The benchmark model is trained with Adam. In the current repository, the learning rate is $5 \times 10^{-4}$. The current training script uses mini batches of size 256 and fixed training epochs. The current benchmark results in this thesis use 10 epochs. The script reports sample wise PCC and MSE on the training and validation sets after each epoch. The benchmark results reported in this thesis are produced with the current repository implementation rather than the original DeepCOP code base.

\section{Proposed model}
\subsection{Architecture}
Figure~\ref{fig:proposed_model} shows the proposed model. The model uses a graph attention network on a biological interaction graph. It predicts one response value for each gene.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.95\linewidth]{figures/proposed_model.png}
    \caption{Structure of the proposed model. The model combines the biological interaction graph, the control profile, and drug target information to predict the gene wise response.}
    \label{fig:proposed_model}
\end{figure}

\noindent The proposed model predicts one response value for each gene. It uses a graph attention network on a biological interaction graph. The model takes three types of information. It uses the biological graph as the interaction structure. It uses the control expression profile as the current cell state. It also uses the drug target vector as the perturbation signal.

\subsubsection{Graph structure and node features}
Prior biological knowledge is represented as a directed graph $\mathcal{G}=(\mathcal{V},\mathcal{E})$ built from OmniPath. Each node is one gene in the selected gene set, so $|\mathcal{V}|=G$. The graph can be written as an adjacency matrix $A \in \mathbb{R}^{G \times G}$. If gene $u$ regulates gene $v$, then $A_{uv} \neq 0$. In the current code, the graph can be used in dense form or sparse form.

\noindent The model starts from one node per gene. The control profile provides one scalar input for each node. The drug target vector also provides one scalar input for each node. These two inputs are projected to a hidden dimension $F$. In the current main setting, $F=64$. The initial node representation matrix is
\begin{equation}
H^{(0)} \in \mathbb{R}^{G \times F}.
\end{equation}
More precisely, the control input and the drug target input are embedded separately and then added:
\begin{equation}
H^{(0)} = \phi_{\mathrm{ctl}}(x_{\mathrm{ctl}}) + \phi_{\mathrm{drug}}(x_{\mathrm{drug}}).
\end{equation}
For a mini batch, the node feature tensor becomes
\begin{equation}
H^{(0)} \in \mathbb{R}^{B \times G \times F}.
\end{equation}

\subsubsection{Cell information}
Two ways to model cell information are considered in this work.

\noindent One way uses a cell identity embedding. In this case, each cell line has one learned vector in $\mathbb{R}^{F}$. All samples from the same cell line share this vector. The same vector is then added to all gene nodes in that sample. This design is simple and easy to optimize. However, it treats the cell state as a fixed label. In the current benchmark configuration, this cell identity embedding is enabled.

\noindent The other way uses a control derived cell context. In this case, the full control profile $x_{\mathrm{ctl}}$ is passed through an encoder and mapped to one context vector in $\mathbb{R}^{F}$. This gives one context vector for each sample, not one fixed vector for each cell line. The context vector is then broadcast to all $G$ gene nodes of the same sample and added to their node features. This design lets the model use the observed control state of the sample, rather than only the cell label.

\subsubsection{Graph attention layers and readout}
The backbone contains $L$ graph attention layers. In the current benchmark setting, $L=4$. Each layer uses multi head attention with $K=4$ heads. Since the hidden width is $F=64$, each head outputs $64/4=16$ features and the concatenated output returns to dimension 64. After the attention update, the model applies dropout, a residual connection, and layer normalization. It then applies a position wise feed forward network, a second dropout, a second residual connection, and a second layer normalization.

\noindent The position wise feed forward network follows the Transformer design introduced by Vaswani et al.~\cite{vaswani2017attention}. In that design, attention is used to mix information across different positions, while the feed forward network applies the same nonlinear transformation to each position separately. This gives the model more expressive power after attention. It also lets the model refine each node representation without changing the graph structure.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.62\linewidth]{figures/gat_flow.png}
    \caption{Flow of the attention block used in the proposed GAT model. The block applies a graph attention layer, dropout, residual addition, and layer normalization. It then applies a position wise feed forward network, followed by dropout, a second residual addition, and a second layer normalization.}
    \label{fig:gat_flow}
\end{figure}

\noindent Figure~\ref{fig:gat_flow} shows the attention related computation in one graph block of the proposed model. When several graph attention layers are stacked, the output of one block becomes the input to the next block.

\noindent After the last graph layer, each node has a final hidden vector $h_{v}^{(L)} \in \mathbb{R}^{F}$. A linear readout maps this vector to one scalar output,
\begin{equation}
\hat{y}_{v}=w_{\mathrm{out}}^{\top} h_{v}^{(L)} + b_{\mathrm{out}},
\end{equation}
where $w_{\mathrm{out}} \in \mathbb{R}^{F}$ and $b_{\mathrm{out}} \in \mathbb{R}$. Stacking these outputs over all genes gives the full prediction $\hat{y} \in \mathbb{R}^{G}$.

\noindent In the current implementation, the readout is applied independently to each node. This design gives one scalar output for each gene node. At batch level, the output shape is $\hat{Y} \in \mathbb{R}^{B \times G}$.

\subsection{Loss function}
The proposed model uses a masked regression loss. Let $m \in \{0,1\}^{G}$ be a gene mask. The masked mean squared error is
\begin{equation}
\mathcal{L}_{\mathrm{mse}}=\frac{1}{B\sum_{g} m_{g}}\sum_{i=1}^{B}\sum_{g=1}^{G} m_{g}\left(y_{ig}-\hat{y}_{ig}\right)^{2}.
\end{equation}
In the current landmark gene setting, the selected target genes match the prediction space, so the mask covers all selected genes.

\noindent The model also uses a sample wise Pearson correlation term. For one sample $i$, the correlation over the selected genes is
\begin{equation}
\mathrm{corr}\!\left(y_{i},\hat{y}_{i}\right)=\frac{\sum_{g}\left(y_{ig}-\bar{y}_{i}\right)\left(\hat{y}_{ig}-\bar{\hat{y}}_{i}\right)}{\sqrt{\sum_{g}\left(y_{ig}-\bar{y}_{i}\right)^{2}}\sqrt{\sum_{g}\left(\hat{y}_{ig}-\bar{\hat{y}}_{i}\right)^{2}}},
\end{equation}
where $\bar{y}_{i}$ and $\bar{\hat{y}}_{i}$ are means over the selected genes. The correlation loss is
\begin{equation}
\mathcal{L}_{\mathrm{pcc}} = 1-\frac{1}{B}\sum_{i=1}^{B}\mathrm{corr}\!\left(y_{i},\hat{y}_{i}\right).
\end{equation}
The main prediction loss is
\begin{equation}
\mathcal{L}_{\mathrm{full}}=\mathcal{L}_{\mathrm{mse}}+\lambda_{\mathrm{pcc}}\mathcal{L}_{\mathrm{pcc}}.
\end{equation}
In the current implementation, $\lambda_{\mathrm{pcc}}=5$.

\noindent The model also uses a counterfactual drug loss. In each training step, one forward pass uses the true drug target vector and another uses a zero drug target vector. Let the second prediction loss be $\mathcal{L}_{\mathrm{cf}}$. The hinge penalty is
\begin{equation}
\mathcal{L}_{\mathrm{hinge}}=\max\!\left(0,\delta-\left(\mathcal{L}_{\mathrm{cf}}-\mathcal{L}_{\mathrm{full}}\right)\right).
\end{equation}
The final objective is
\begin{equation}
\mathcal{L}=\mathcal{L}_{\mathrm{full}}+\lambda_{\mathrm{cf}}\mathcal{L}_{\mathrm{hinge}}.
\end{equation}
This term encourages the factual prediction to be better than the counterfactual one~\cite{hadsell2006contrastive, schroff2015facenet, wachter2017counterfactual}.

\subsection{Optimization}
The proposed model is trained with Adam. In the current benchmark setting, the learning rate is $5 \times 10^{-4}$. The training uses mini batches of size 32 and fixed training epochs. The current benchmark results use 50 epochs. In each training step, the loop computes one factual forward pass and one counterfactual forward pass. It then backpropagates the full counterfactual training objective. The training loop reports sample wise PCC and MSE after each epoch. The current benchmark configuration uses hidden dimension 64, four attention heads, dropout 0.2, four graph attention layers, and the zero drug counterfactual setting.

\section{Training and evaluation protocol}
The same target definition is used for both models, but the data pairing strategy differs between training and test. In training, one treatment profile can be matched to several controls. In test, each treatment profile is matched to one control. The split is applied before the final treatment control matching. After that step, the training and test control pools are separated. This design reduces leakage.

\noindent Three split settings are used. Warm split uses a random sample split. Cold drug split holds out test drugs from training. Cold cell split holds out test cell lines from training.

\noindent In the current pipeline, the training set uses multiple matched controls for each treatment profile. The default number is three controls per treatment profile. If fewer controls are available, sampling is done with replacement. The test set uses one matched control for each treatment profile. This makes the test setting more conservative.

\noindent Performance is reported with mean squared error and sample wise Pearson correlation coefficient. In addition, this thesis also reports top gene precision and regulation sign accuracy in the results chapter. Attention weights from the proposed model are used only for interpretation. They are not used to change the prediction after training.

\chapter{Methodology}
\noindent This chapter presents the methodological design of the thesis. It covers the problem formulation, the proposed model, related baseline models, and the experimental setup used for training and evaluation. Figures from this chapter were created by the author.

\section{Target}
This thesis studies prediction of gene expression changes after drug treatment. The detailed construction of this target is described in Section~\ref{sec:prediction_target_construction}. In the model, the supervised target is defined as
\begin{equation}
y = x_{\mathrm{trt}} - x_{\mathrm{ctl}}.
\end{equation}
\noindent where $x_{\mathrm{ctl}}$ is the matched control profile and $x_{\mathrm{trt}}$ is the treated profile. The model predicts a response vector $\hat{y}$. For a mini batch of size $B$, the same target definition is applied sample by sample.

\section{Inputs}
\noindent A matched control profile, a drug representation, and cell information are used as the three main inputs. These inputs use the same gene order, so the control vector, the drug vector, the graph matrix, and the predicted response are all aligned gene by gene.

\subsection{Control data}
The matched control profile $x_{\mathrm{ctl}}$ represents the baseline state of the cell before drug treatment. In the model, it is used as the measured pre treatment input for each sample.

\noindent In the main configuration, $G=978$ landmark genes are used, so each control sample is a vector of continuous expression values. As shown in Figure~\ref{fig:ctl_node_projection}, each gene value is mapped to the corresponding graph node and projected to the hidden dimension. This gives every node a starting feature based on the measured control expression.

    \label{fig:ctl_node_projection}
\end{figure}

\subsection{Drug target}
The main drug input is a binary target vector $x_{\mathrm{drug}}$. Each entry corresponds to one gene in the selected gene set. A value of 1 indicates that the gene is an annotated target of the drug, while a value of 0 indicates that no target relation is recorded for that gene.

\begin{figure}[htbp]

After adding one extra feature dimension, the same shared projection layer maps the scalar input of each gene to a 64 dimensional node feature.}
    \label{fig:drug_target_projection}
\end{figure}

\subsection{Biological graph}
The proposed architecture uses a directed biological graph $\mathcal{G}=(\mathcal{V},\mathcal{E})$ derived from the OmniPath database. Each node represents one gene, and each directed edge represents a known effect from one gene to another. If gene $u$ can affect gene $v$, the graph includes a directed edge from $u$ to $v$. The same graph can also be written as an adjacency matrix $A$.

\noindent The graph stores not only whether two genes are connected, but also whether the effect is activating or inhibitory. Here gene $u$ is the source node and gene $v$ is the target node. If gene $u$ activates gene $v$, the edge from $u$ to $v$ is assigned a positive sign. If gene $u$ inhibits gene $v$, the edge is assigned a negative sign. In this way, the graph tells the model not only where information can flow, but also whether the incoming signal should increase or oppose the current state of the target gene.

\noindent This sign can be written as
\begin{equation}
s_{u \rightarrow v}=
\begin{cases}
1, & \text{if gene } u \text{ activates gene } v,\\
-1, & \text{if gene } u \text{ inhibits gene } v.
\end{cases}
\end{equation}
The message from gene $u$ to gene $v$ is then adjusted by this sign:
\begin{equation}
m_{u \rightarrow v}= s_{u \rightarrow v}\, h_u.
\end{equation}
Here $h_u$ is the current representation of gene $u$. A positive sign keeps the message in the same direction, while a negative sign reverses it.

\subsection{Cell information}

\noindent Using a cell identity embedding is one option. In that case, each cell line is assigned one learned vector, so all samples from the same cell line share the same representation.

The same cell embedding is shared by all samples from the same cell line.}
    \label{fig:cellid_embedding}
\end{figure}

\noindent Another option is to use cell context. Here the matched control profile is encoded into a sample specific context vector $c_{\mathrm{ctx}}$~\cite{evans2024gsnn,guo2026xpert}. This uses the measured pre treatment expression state rather than a fixed cell label.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.95\linewidth]{figures/cell_context.png}
    \caption[Control Derived Cell Context]{Control derived cell context. The control profile is normalized and encoded into a sample specific context vector. This context summarizes the baseline expression state of the sample before drug perturbation.}
    \label{fig:cell_context}
\end{figure}

\noindent In the graph model used later in this thesis, the cell context vector $c_{\mathrm{ctx}}$ is copied to all $G$ gene nodes and added to their initial node features~\cite{guo2026xpert}.

\subsection{Summary}
\noindent Many studies in perturbation prediction use extra input features, such as molecular fingerprints, gene ontology features, or mutation profiles~\cite{woo2020deepcop,guo2026xpert,Rogers2010ECFP,Ashburner2000GO}. The main experiments in this thesis use a simpler input setting. All models use the matched control profile and the drug representation. The proposed model also uses cell context information, while the two baselines do not.

\noindent This simpler design makes the comparison easier to follow. With fewer extra inputs, the comparison focuses more directly on the matched control profile, the drug input, and the added cell context.
\section{Base model}
\subsection{Overview}
Figure~\ref{fig:base_model_structure} shows the baseline model. It is a fully connected design~\cite{woo2020deepcop}, without using a biological interaction graph. The output layer predicts a mean response and an uncertainty related value for each gene.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.56\linewidth]{figures/base_model_structure.png}
    \caption[Baseline Model Structure]{Structure of the baseline model. In the reported experiments, the input is the concatenation of the 978 dimensional control expression vector and the 978 dimensional drug target vector, giving an input shape of $[B,1956]$ for a mini batch of size $B$. The circles denote hidden units in fully connected layers, and the dotted vertical marks indicate omitted repeated units. The blue output boxes labeled $\mu$ denote the mean response predictions for the 978 genes, and the pink output boxes labeled $\log \sigma^{2}$ denote the corresponding log variance predictions.}
    \label{fig:base_model_structure}
\end{figure}

\noindent The baseline model uses the control profile and drug input introduced above and the two input vectors are concatenated:
\begin{equation}
z = [x_{\mathrm{ctl}} \Vert x_{\mathrm{drug}}].
\end{equation}
For a mini batch, the same input is written as $Z$. The model then applies two fully connected blocks. Each block uses a dense layer, batch normalization, ReLU, and dropout. The output stage predicts two vectors of length $G$, namely a mean vector $\mu$ and a log variance vector $\log \sigma^{2}$. If these two vectors are stacked gene by gene, the final output for one sample can be written as
\begin{equation}
\left[\mu, \log \sigma^{2}\right].
\end{equation}
For a full mini batch, the same output structure is used for all samples.

\subsection{Loss function}
The baseline model predicts both a mean response and a log variance. The prediction target is the same response vector used in the thesis,
\begin{equation}
y = x_{\mathrm{trt}} - x_{\mathrm{ctl}},
\end{equation}
and the base error term is a Gaussian negative log likelihood. The likelihood term is
\begin{equation}
\mathcal{L}_{\mathrm{nll}}^{\mathrm{base}}=\frac{1}{BG}\sum_{i=1}^{B}\sum_{g=1}^{G}\frac{1}{2}\left[\log \sigma_{ig}^{2}+\frac{\left(y_{ig}-\mu_{ig}\right)^{2}}{\sigma_{ig}^{2}}\right].
\end{equation}
where $B$ is the mini batch size. Here $\mu_{ig}$ is the predicted mean response and $\sigma_{ig}^{2}$ is the predicted variance for gene $g$ in sample $i$.

\noindent The baseline also includes the same Pearson correlation term computed separately for each sample,
\begin{equation}
\mathcal{L}_{\mathrm{pcc}}^{\mathrm{base}} = 1-\frac{1}{B}\sum_{i=1}^{B}\mathrm{corr}\!\left(y_{i},\mu_{i}\right),
\end{equation}
so the final objective is
\begin{equation}
\mathcal{L}_{\mathrm{base}}=\mathcal{L}_{\mathrm{nll}}^{\mathrm{base}}+\lambda_{\mathrm{pcc}}\mathcal{L}_{\mathrm{pcc}}^{\mathrm{base}}.
\end{equation}
In the reported baseline setting, a fixed PCC weight is used. This keeps the baseline loss aligned with the proposed model, because both models are trained to reduce prediction error for each gene while also preserving the overall response pattern across genes.

\section{GSNN baseline}
GSNN~\cite{evans2024gsnn} is the graph based baseline in this thesis. It is evaluated on the same paired perturbation data and the same biological graph as the proposed model, but the computation is different.

\subsection{Overview}
\noindent GSNN uses only the matched control profile and the drug input vector,
\begin{equation}
x_{\mathrm{GSNN}} = [x_{\mathrm{ctl}}; x_{\mathrm{drug}}].
\end{equation}
This baseline does not use the extra cell context input used by the proposed model. The training target is the response vector
\begin{equation}
y = x_{\mathrm{trt}} - x_{\mathrm{ctl}},
\end{equation}
so the model predicts one response value for each gene rather than the raw treated expression profile.

\noindent The implementation builds a graph with several node groups. For each gene, there is one control input node, one drug input node, one internal function node, and one output node. The control and drug inputs connect to the corresponding function node. The function nodes are connected by the biological graph. Each function node then connects to one output node, which produces the predicted response for that gene.

\noindent The internal update rule is not the same as the graph attention mechanism used in the proposed model. In this model, GSNN uses sparse linear updates inside residual blocks, and the graph decides which connections are allowed. Information from incoming edges is collected into hidden channels of each function node, processed by a nonlinearity and an MLP applied separately to each node, and then sent back to the outgoing edges. GSNN uses the graph during message passing, but it does not learn a separate importance weight for every edge.

\noindent The output of GSNN is a prediction vector with one response value for each gene and with the same dimension as $y$. Compared with the proposed model, it does not include control derived cell context or graph attention based message passing.

\subsection{Loss function}
\noindent GSNN is trained with a response prediction loss only. If the prediction for sample $i$ is $\hat{y}_{i}$ and the target is $y_{i}$, the loss is
\begin{equation}
\mathcal{L}_{\mathrm{GSNN}}=\frac{1}{BG}\sum_{i=1}^{B}\sum_{g=1}^{G}(y_{ig}-\hat{y}_{ig})^{2}.
\end{equation}
\noindent This objective only trains the response prediction itself. It does not include a separate uncertainty term, a PCC term, or a counterfactual hinge term.

\subsection{Training settings}
\noindent GSNN is trained on the same paired perturbation data and under the same split settings as the proposed model. The same response target $y = x_{\mathrm{trt}} - x_{\mathrm{ctl}}$ is used. Optimization uses mini batches and standard gradient based training. The implementation is adapted from the code released by the original authors, while the input interface is modified to match the data modalities available in this thesis. This keeps the comparison focused on the model design rather than on differences in the data pipeline.

\noindent The trainable parameter count of GSNN also depends on the graph size. Under the reported setting, the graph contains 978 gene nodes and 1628 biological edges between function nodes before self loops are added. The implementation adds one self loop per function node. It also uses 8 hidden channels per node, 3 residual graph blocks, and a node MLP hidden width of 64. Table~\ref{tab:gsnn_param_count} summarizes the main trainable parts. The detailed calculation steps are listed in Appendix~\ref{app:param_count_details}.

\section{Proposed model}
\subsection{Overview}
Figure~\ref{fig:proposed_model} shows the proposed model. It uses a graph attention network on a biological interaction graph and predicts one response value for each gene.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.95\linewidth]{figures/proposed_model.png}
    \caption[Proposed Model Structure]{Structure of the proposed model. The colored blocks at the top left denote the three input types, namely drug target, cell related input, and control expression. The circles in the graph denote gene nodes, and the directed arrows denote biological edges along which messages can pass. The dashed orange boxes beside the nodes show learned node feature vectors. The larger dashed orange box at the top right shows the readout head with two outputs, where $\mu$ is the predicted mean and $\log \sigma^{2}$ is the predicted log variance.}
    \label{fig:proposed_model}
\end{figure}

\noindent The graph, node features, and cell information are introduced in the input section above. The model combines these inputs to predict the response profile. The same uncertainty aware graph backbone is used throughout the proposed model analyses in this thesis. The ablation analysis changes how cell information is provided, but the model still predicts both a mean response and an uncertainty value for each gene.

\subsection{Node features}
The proposed model starts with one node per gene. The control profile provides one scalar input for each node, and the drug target vector provides another scalar input. These inputs are projected to a hidden dimension $F$. The initial node representation matrix is denoted by $H^{(0)}$.
\noindent The control input and the drug target input are embedded separately, and the cell context is copied to all $G$ nodes before it is added:
\begin{equation}
H^{(0)} = \phi_{\mathrm{ctl}}(x_{\mathrm{ctl}}) + \phi_{\mathrm{drug}}(x_{\mathrm{drug}}) + C_{\mathrm{ctx}}.
\end{equation}
\noindent Here $C_{\mathrm{ctx}}$ denotes the matrix formed by repeating the same context vector $c_{\mathrm{ctx}}$ across all $G$ gene nodes.

\noindent For a mini batch, the same node feature construction is applied to every sample.
\noindent When cell information is added here, each gene node starts with control and drug signals together with information about the current cell state. Message passing therefore begins from a representation that already reflects the sample context.

\subsection{Graph multi-head attention block}
\noindent The backbone uses several graph attention layers with multi head attention. The hidden width is divided evenly across the heads, and the concatenated output returns to the original hidden dimension. Cell information is not inserted directly into the attention score. Instead, the cell context vector is added to the node features before message passing starts.

\noindent The general GAT computation and the role of residual connections, layer normalization, and the small two layer block after attention are introduced in the theory chapter. In the proposed model, each block uses standard multi head graph attention for neighbor aggregation, followed by dropout, residual addition, and layer normalization. The small two layer block in \eqref{eq:ffn_block} is then applied to each node, followed again by dropout, residual addition, and layer normalization.

\noindent The complete attention layer with attention block is illustrated in Figure~\ref{fig:gat_attention_block} in the theory chapter. In the proposed model, this block operates on the node representations prepared in the input stage, which already contain the sample context. When several graph attention layers are stacked, the output of one block becomes the input to the next block.

\subsection{Output layer}
\noindent After the last graph layer, each node has a final hidden vector $h_{v}^{(L)}$. The output layer uses two parallel linear readouts. One predicts the mean response,
\begin{equation}
\mu_{v}=w_{\mu}^{\top} h_{v}^{(L)} + b_{\mu},
\end{equation}
and the other predicts a log variance term,
\begin{equation}
\log \sigma_{v}^{2}=w_{\sigma}^{\top} h_{v}^{(L)} + b_{\sigma},
\end{equation}
where $w_{\mu}, w_{\sigma}$ are learned weight vectors and $b_{\mu}, b_{\sigma}$ are bias terms. Stacking these outputs over all genes gives the full mean prediction $\mu$ and the full log variance prediction $\log \sigma^{2}$.

\noindent Both outputs are computed from the same final hidden vector $h_{v}^{(L)}$, but they do not use the same parameters. The mean prediction uses $w_{\mu}, b_{\mu}$, while the log variance prediction uses $w_{\sigma}, b_{\sigma}$. The same node representation is therefore projected in two different ways, so the model can learn one mapping for the expected response and another for the uncertainty related value.


\subsection{Loss function}
\noindent The proposed model is trained with a combined objective. Part of this design is the same as in the baseline. Both models predict a mean response and a log variance and use a Gaussian negative log likelihood together with a Pearson correlation term computed separately for each sample. The probabilistic interpretation of the output and the general Gaussian negative log likelihood are introduced in the theory chapter in \eqref{eq:gaussian_assumption} and \eqref{eq:gaussian_nll}. For sample $i$ and gene $g$, the target is compared with the predicted mean $\mu_{ig}$ and predicted log variance $\log \sigma_{ig}^{2}$, so the likelihood term is
\begin{equation}
\mathcal{L}_{\mathrm{nll}}=\frac{1}{BG}\sum_{i=1}^{B}\sum_{g=1}^{G}\frac{1}{2}\left[\log \sigma_{ig}^{2}+\frac{(y_{ig}-\mu_{ig})^{2}}{\sigma_{ig}^{2}}\right].
\end{equation}
Here $B$ is the mini batch size and $G$ is the number of genes. The term $y_{ig}$ is the true response, $\mu_{ig}$ is the predicted mean, and $\sigma_{ig}^{2}$ is the predicted variance. In the implementation, the model predicts $\log \sigma_{ig}^{2}$ for numerical stability.

\noindent The model also uses a Pearson correlation term computed separately for each sample. For one sample $i$, the correlation over the selected genes is
\begin{equation}
\label{eq:pcc_corr}
\mathrm{corr}\!\left(y_{i},\mu_{i}\right)=\frac{\mathrm{cov}(y_i,\mu_i)}{\mathrm{std}(y_i)\,\mathrm{std}(\mu_i)},
\end{equation}
where the covariance and standard deviations are computed over genes within sample $i$. The correlation loss is
\begin{equation}
\label{eq:pcc_loss}
\mathcal{L}_{\mathrm{pcc}} = 1-\frac{1}{B}\sum_{i=1}^{B}\mathrm{corr}\!\left(y_{i},\mu_{i}\right).
\end{equation}
This form is used because the training objective is minimized. A larger Pearson correlation should improve the model, so the optimization uses $1-\mathrm{PCC}$ rather than $\mathrm{PCC}$ itself.

\noindent The main prediction objective is
\begin{equation}
\mathcal{L}_{\mathrm{full}}=\mathcal{L}_{\mathrm{nll}}+\lambda_{\mathrm{pcc}}\mathcal{L}_{\mathrm{pcc}}.
\end{equation}
The likelihood term reduces prediction error while learning an uncertainty estimate for each gene. The PCC term encourages agreement in the shape of the response profile across genes. In the reported implementation, $\lambda_{\mathrm{pcc}}$ is set to 5.

\noindent A related variant of the proposed model also adds a counterfactual drug loss, abbreviated here as the CF loss. Following the general idea of counterfactual learning~\cite{guo2025counterfactual_graphs}, one forward pass uses the true drug target vector and another uses a zero drug target vector. Let $\mathcal{L}_{\mathrm{cf}}$ denote the same prediction objective as $\mathcal{L}_{\mathrm{full}}$, but computed from the zero drug forward pass. The counterfactual branch therefore predicts the same outputs as the main branch, but under the zero drug input. The hinge penalty is
\begin{equation}
\mathcal{L}_{\mathrm{hinge}}=\max\!\left(0,\delta-\left(\mathcal{L}_{\mathrm{cf}}-\mathcal{L}_{\mathrm{full}}\right)\right).
\end{equation}
The final objective is
\begin{equation}
\mathcal{L}=\mathcal{L}_{\mathrm{full}}+\lambda_{\mathrm{cf}}\mathcal{L}_{\mathrm{hinge}}.
\end{equation}
This term encourages the prediction with the real drug input to be better than the prediction with the zero drug input.

The main benchmark, the ablation analysis, the uncertainty analysis, and the warm split data efficiency study all keep the same graph backbone, uncertainty output, target definition, and split design. Optimization uses Adam with a fixed learning rate and mini batch training. In the counterfactual variant, one forward pass uses the true drug target vector and another uses a zero drug vector.

\section{Evaluation Metrics}
\subsection{Split settings}
\noindent Three split settings are used. Warm split uses a random sample split and evaluates performance on data that look similar to the training set. Cold drug target split holds out test drugs from training and measures how well the model works on drugs it has not seen before. Cold cell split holds out test cell lines from training and measures how well the model works on cell lines it has not seen before. In this pipeline, the training set uses multiple matched controls for each treatment profile.

\subsection{Average baselines}
In addition to the learned models, this thesis also reports several simple average based baselines. These baselines do not train a neural network. Instead, they make predictions directly from averages computed on the training set, showing how much the learned models improve over very simple rules.

\noindent The simplest baseline is \texttt{Mean}, which is obtained by averaging all training response vectors gene by gene. This produces one fixed vector of length 978, and that same vector is used as the prediction for every test sample. As a result, \texttt{Mean} ignores both drug identity and cell identity and represents only the average response pattern observed in the training set.
\begin{equation}
\bar{y}_{\mathrm{all}}=\mathrm{mean}\!\left(Y_{\mathrm{train}}\right),
\qquad
\hat{y}_j=\bar{y}_{\mathrm{all}} \ \text{for every test sample } j.
\end{equation}

\noindent When this baseline is evaluated with PCC, the same average vector is compared with each test sample separately. For every test sample, one PCC value is computed with Eq.~\ref{eq:pcc_corr}, and the final reported test PCC is the mean of these values across the full test set. Figure~\ref{fig:mean_pcc_logic} illustrates this calculation process.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.98\linewidth]{figures/mean_pcc.png}
    \caption[Mean Baseline PCC]{Illustration of how mean test PCC is computed for the \texttt{Mean} baseline. An average response vector is first estimated from the training set and then repeated as the prediction for every test sample. PCC is computed between each predicted row and the corresponding true response row using Eq.~\ref{eq:pcc_corr}.}
    \label{fig:mean_pcc_logic}
\end{figure}

\noindent Another baseline is \texttt{mean\_cell}. In this case, the training samples are grouped by cell line, and the response vectors within each group are averaged gene by gene. During testing, each sample is assigned the average vector of its corresponding cell line. This baseline uses cell identity, while still ignoring which drug is applied.
\begin{equation}
\bar{y}_{\mathrm{cell}}=\mathrm{mean}(\text{training responses from one cell line}),
\qquad
\hat{y}=\bar{y}_{\mathrm{cell}}.
\end{equation}
Here, $\bar{y}_{\mathrm{cell}}$ means the average response vector of the cell line to which the test sample belongs.

\noindent When \texttt{mean\_cell} is evaluated with PCC, the test samples are first grouped by cell line. For each cell line that appears in the training set, one average response vector is computed from the corresponding training samples. Each test sample then receives the average vector of its own cell line as prediction, and PCC is computed with Eq.~\ref{eq:pcc_corr}. The final reported test PCC is the mean of these PCC values across the full test set. Figure~\ref{fig:mean_cell_logic} illustrates this calculation process.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.98\linewidth]{figures/mean_cell.png}
    \caption[Mean Cell PCC]{Illustration of how mean test PCC is computed for the \texttt{mean\_cell} baseline. The training responses are first grouped by cell line, and one average response vector is computed for each cell. Each test sample then receives the average vector of its corresponding cell line. PCC is computed between each predicted row and the corresponding true response row using Eq.~\ref{eq:pcc_corr}, and the final test PCC is the mean of these values.}
    \label{fig:mean_cell_logic}
\end{figure}

\noindent \texttt{mean\_drug} is computed in the same way as \texttt{mean\_cell}, except that the grouping variable is the drug rather than the cell line. For each drug in the training set, the response vectors are averaged gene by gene, and each test sample receives the average vector of its drug.
\begin{equation}
\bar{y}_{\mathrm{drug}}=\mathrm{mean}(\text{training responses from one drug}),
\qquad
\hat{y}=\bar{y}_{\mathrm{drug}}.
\end{equation}
Here, $\bar{y}_{\mathrm{drug}}$ means the average response vector of the drug used in the test sample.

\noindent Not every baseline is meaningful in every split. In the cold drug target split, the test drugs are unseen during training, so a drug specific average cannot be computed for them, so \texttt{mean\_drug} is omitted. In the cold cell split, the same logic applies to unseen cell lines, so \texttt{mean\_cell} is omitted there. By contrast, \texttt{Mean} can always be evaluated because it does not depend on any specific drug or cell label.

\subsection{Error metrics}
This metric shows how close the predicted response values are to the observed response values. A lower MSE means that the predicted perturbation profile is closer to the true profile.

\begin{equation}
\label{eq:test_mse}
\mathrm{MSE}=\mathrm{mean}\!\left((y-\hat{y})^2\right).
\end{equation}

\noindent MSE checks not only the direction of change but also the approximate size of the response. This matters when the strength of perturbation is important. However, MSE alone does not show whether the model captures the overall response pattern well. A model may not get the exact numbers right but still preserve the main biological structure of the profile. In this thesis, MSE follows the same squared error view used in the loss terms introduced above.

\subsection{Correlation metrics}
The main correlation metric is Pearson correlation coefficient (PCC). This metric compares the predicted and true response profiles within one sample and asks whether they follow a similar pattern across genes. A higher PCC means that genes predicted to increase or decrease tend to match the observed trend more closely.

\noindent Perturbation analysis often cares about whether the overall gene pattern is correct, but a model can still be informative if it identifies which genes move together and which genes change in opposite directions, even when the exact response size is not perfectly matched. So we can use PCC together with MSE to evaluate the final result. The PCC definition follows Eq.~\ref{eq:pcc_corr}, and the related loss function is given in Eq.~\ref{eq:pcc_loss}.

\noindent PCC values in this task should not be compared directly with accuracy values from tasks such as classification. Here the model must predict a full continuous response profile across 978 genes for each sample. A good PCC requires the model to recover the relative pattern across many genes, not just to make one correct decision. In addition, drug response data contain measurement noise, different cell states, incomplete drug target information, and many genes with only weak responses. For these reasons, even a modest PCC can still indicate that the predicted gene pattern follows the observed pattern to a useful degree.

\noindent The evaluation also reports regulation sign accuracy. This metric asks whether the model predicts the correct direction of regulation for each gene, for example, whether the gene goes up or down. This matters because the sign of change tells whether a gene is up regulated or down regulated after treatment.

\begin{equation}
\label{eq:sign_acc}
\mathrm{Acc}_{\mathrm{sign}}=\frac{\text{number of genes with correct sign}}{\text{number of compared genes}}.
\end{equation}

\noindent This score is computed for each sample and then averaged across the test set, checking whether the predicted direction of change is correct.

\subsection{Precision metrics}
The evaluation also reports top gene precision. This metric asks whether the model can recover the genes with the strongest positive or negative responses. In practice, this is measured from ranked predicted and true response vectors. The goal is not to treat every small change equally, but to test whether the model identifies the most strongly affected genes.

\noindent For one sample, positive precision at 20 is defined as
\begin{equation}
\label{eq:pos_p20}
\mathrm{Pos\ P@20}=\frac{\text{predicted top 20 up genes that also appear in true top 100 up genes}}{20}.
\end{equation}

\noindent Negative precision at 20 is defined in the same way for the down regulated genes,
\begin{equation}
\label{eq:neg_p20}
\mathrm{Neg\ P@20}=\frac{\text{predicted top 20 down genes that also appear in true top 100 down genes}}{20}.
\end{equation}

\noindent This metric is useful because later analysis often focuses on the strongest genes. These genes are more likely to be discussed as key pathway genes or as representative signals of the drug effect. A model with good top gene precision is better at ranking the strongest changed genes.

\subsection{Data efficiency metrics}
Beyond the standard split settings, this thesis also includes a drug cell pair data efficiency evaluation on the warm split. In this setting, the test set is kept fixed, while the amount of available training data is increased step by step under several fixed settings. This makes it possible to study how quickly different models improve as more training data becomes available.

\noindent This reduction is not done by randomly dropping samples from the whole training set. Instead, it is applied to each drug cell pair. Here a drug cell pair means one specific drug tested in one specific cell line. For example, all repeated measurements of drug A in the A549 cell line form one pair, while the same drug A in MCF7 is counted as a different pair. If the same drug is measured several times in the same cell line, all of these repeated samples belong to the same pair.

\noindent Two simple data settings are used. In the one shot setting, only one training sample is kept for each drug cell pair. In the fraction based setting, only a fixed fraction of the available samples is kept for each pair. For example, if one pair has ten training samples, then a 30\% setting keeps about three of them, while an 80\% setting keeps about eight. The kept samples are chosen randomly within each pair without replacement. If a pair has very few samples, the procedure still keeps at least one sample when the setting is positive. The test set is not changed during this process, so all models are compared on the same evaluation data.

\noindent The reason for testing settings such as one shot, 30\%, or 80\% is that they represent different amounts of available data. One shot is an extreme low data setting. It tests whether the model can still learn when each drug cell pair is seen only once. Mid range settings such as 30\% show whether the model improves steadily when more repeated measurements become available. Higher settings such as 80\% show whether performance is already near its highest point or whether the model still benefits from more data. Together, these settings make it possible to compare not only final accuracy, but also how the models improve as more training data are added.

\noindent This design has a clear advantage. It prevents a few large drug cell pairs from dominating the reduced training set. If samples were removed at random, common pairs would still keep many examples, while rare pairs could disappear entirely. That would make the comparison less fair and less informative about data efficiency for each pair. With the pair based design, each observed drug cell combination remains represented, and the comparison focuses on how many repeated samples for each pair are needed.

\chapter{Discussion}

\section{Method}
\noindent UPert was designed for drug effects that spread through the gene network. Known drug targets and a biological interaction graph provide structure without using a standard feed forward network. This design reflects the assumption that a perturbation usually starts from a limited set of target genes and then propagates through connected regulators and pathways rather than affecting every output gene independently. The graph prior therefore gives the model a biologically informed way to organize information flow, which is especially useful when the training data are limited or when generalization to unseen drugs or unseen cell contexts is required.

\subsection{Main model setting}
\noindent The main UPert comparison in this thesis combines a graph attention backbone, matched control expression, drug target input, and control derived cell context. This main comparison is the basis for the three split comparisons with DeepCOP and GSNN. Separate parts of the thesis then examine additional questions. The ablation analysis compares cell identity with cell context inside the same backbone. A separate uncertainty enabled UPert run is used for the uncertainty analysis. The warm split data efficiency analysis studies how performance changes when the training budget is reduced.

\subsection{Motivation for the Cell Context}
\noindent Cell context means a summary of the state of one sample before the drug is applied. In this thesis, it is derived from the matched control profile, so it summarizes what the cell already looks like before perturbation. This is different from a cell identity label, which only tells the model which cell line the sample belongs to. Two samples from the same cell line can still start from somewhat different gene expression patterns, and the control profile can reflect that difference while the label cannot. This is especially useful in cold cell, where the test cell line is unseen and a fixed cell embedding gives little direct information about the actual starting state of the sample.

\subsection{Motivation for the CF loss}
\noindent The CF loss is introduced to reduce one specific risk in this task. The model receives several informative inputs at the same time, especially the matched control profile and the cell related context. These inputs are useful, but they also make it possible for the model to explain part of the response without relying enough on the drug signal itself. The reason is that the control profile and the cell context already describe the starting state of the sample. If a large part of the response can be approximated from that state alone, the model may reduce the loss by learning broad cell dependent response patterns while using the drug target input only weakly. This is a problem because the drug input represents the perturbation itself, while the other inputs mainly describe the baseline state. If that happens, the model can still obtain a reasonable training loss while becoming less sensitive to the drug input.

\noindent The counterfactual branch addresses this problem in a direct way. During training, one forward pass uses the real drug input and another uses a zero drug input. The CF loss then encourages the prediction with the real drug signal to be better than the prediction with the counterfactual input. In simple terms, this acts as a constraint that pushes the model to use the drug information instead of treating it as optional.

\noindent This idea is especially relevant in cold cell. In that split, the model must generalize to unseen cell lines, and the baseline state can dominate the prediction if the drug input is not used strongly enough. The updated drug input check supports this motivation. The CF variant is more sensitive to removing the drug input in all three splits, and the effect is largest in cold cell. This suggests that the CF loss does not only add another optimization term. It changes how strongly the model depends on the perturbation signal, which is exactly the intended purpose.

\subsection{Purpose of the comparison}
\noindent The baseline comparison serves two different purposes. DeepCOP shows what can be achieved without a graph, while GSNN provides a graph based baseline with a different message passing rule from UPert. The ablation analysis adds another comparison by testing how cell information should enter the model. It is included to compare a simple cell identity input with the control derived cell context inside the same backbone.

\section{Result}
\subsection{Overall Result}
\noindent In this benchmark, incorporating known molecular structure is associated with better prediction quality, although the size of the improvement depends on the test setting. In the three split comparison, UPert still gives the most consistent results across the main metrics among the learned models. The no-CF variant is stronger in warm and cold drug target, while the CF variant becomes stronger in cold cell. This split dependent pattern appears in MSE, PCC, top gene precision, and sign accuracy. In cold cell, the mean\_drug baseline gives the lowest MSE overall, but it is still weaker than UPert on PCC. This is important because drug response prediction is not a single number problem. A useful model should reduce numerical error, preserve the overall gene pattern, and recover the strongest changed genes.

\subsection{Why cold cell remains difficult}
\noindent The split comparison also shows a clear limit. Cold cell remains difficult because the model must transfer to a new baseline state, and that state changes how the same drug effect moves through the system. This difficulty still appears in the updated results even though CF UPert becomes the strongest learned variant in that split. The graph gives a stable prior structure, but it cannot remove the difficulty caused by a new cell background.

\subsection{DeepCOP and UPert generalization}
\noindent DeepCOP shows a different pattern between these two test settings. Its cold cell result is still better than its cold drug target result. This should not be explained by the matched control profile alone, because all three learned models receive that same input. A more likely explanation is that the cold drug target split asks the model to generalize drug effects to compounds that were not seen during training, and this seems harder for a feed forward baseline without an explicit graph prior. This may help explain why both UPert variants stay clearly stronger than DeepCOP on PCC in this benchmark. Drug effects do not appear independently across genes. They spread through connected regulators and pathways. A feed forward network has to infer these relations only from the benchmark samples, while UPert already uses known links between genes.

\subsection{Meaning of the evaluation metrics}
\noindent The metric comparison provides another insight. Sign accuracy still gives a weaker and more limited view than PCC and top gene precision. Predicting the correct direction of change is not the same as predicting the full response profile. A model can get many signs right while still missing the relative size or the detailed shape of the response. In the updated comparison, however, sign accuracy now follows the same split dependent pattern as MSE and PCC inside UPert, with no-CF stronger in warm and cold drug target and CF stronger in cold cell. For this task, PCC and top gene precision still give a more useful view of practical prediction quality than sign agreement alone.

\subsection{Comparison with mean baselines}
\noindent The comparison with the simple mean baselines is also informative. In some settings, a very simple average based rule remains competitive, especially on MSE. The clearest case is cold cell, where mean\_drug gives the lowest MSE overall. This suggests that part of the benchmark can still be explained by central tendency in the response data. A strong graph model should therefore not only improve the average numerical error, but also show clearer gains on response pattern metrics such as PCC and top gene precision. These results do not necessarily mean that drug information is intrinsically more important than cell information. Rather, they suggest that drug specific average responses are more directly reusable in this task, whereas cell effects are more context dependent and are not well captured by a simple cell wise mean baseline.

\subsection{Why mean drug can be strong}
\noindent The strong performance of mean\_drug is not as surprising as it may first appear. This baseline uses the average response of the same drug from the training set and reuses it at test time. In warm and cold cell, the drug identity is still seen during training, so the baseline can start from a signal that is already close to the dominant perturbation pattern of that compound. If a large part of the response is drug specific and is shared across many cell contexts, then a simple drug wise average can already give a low MSE.

\noindent This is especially relevant in cold cell. That split asks the model to generalize to unseen cell lines, but the test drugs are still known. In that situation, a learned model must estimate how the same drug response changes with a new cell background. This is harder than reusing the average response of a known drug. The mean\_drug baseline does not try to model the full cell specific deviation. It only predicts the dominant average effect. That can be enough to outperform all learned models on MSE, because a stable average can have lower variance than a model that makes more detailed but less reliable adjustments.

\noindent At the same time, it is also still weaker than both UPert variants on PCC in the updated comparison. This suggests that the baseline captures the broad average effect of a known drug, but it does not recover the sample specific profile as well as the graph based model. The result therefore highlights an important property of the benchmark. Reusing known drug averages is already strong in some settings, but it is not a complete solution to perturbation prediction.

\subsection{Ablation results}
\noindent The ablation analysis supports the importance of baseline state modeling. In the reported cell information ablation, both variants keep the CF loss and differ only in how cell information is provided. Under that setting, replacing cell identity with control derived cell context improves both MSE and PCC in all three splits, and the gain is much larger in cold cell. This suggests that the measured control profile becomes especially valuable when the test cell line was never seen during training.

\subsection{Drug target contribution}
\noindent The drug target contribution analysis answers a different but closely related question. It asks whether the model prediction really depends on the perturbation input rather than mainly on the baseline cell state. In that test, the drug target vector is replaced with zeros at test time. The no-CF model changes only slightly, but the CF variant shows a much larger performance drop in all three splits, and the difference is largest in cold cell. This also helps explain why the CF loss is most useful in cold cell but gives smaller gains, or slight trade offs, in the other splits. Cold cell requires stronger generalization beyond the seen cell backgrounds, so discouraging shortcut use of baseline information is more helpful there. This gives more direct support for the intended role of the CF loss. It does not only change the optimization objective. It also makes the model use the drug target information more strongly when forming the prediction. Together with the cell context ablation, this result supports the same interpretation. Accurate prediction requires both a good description of the starting cell state and sufficient use of the perturbation signal.

\subsection{Uncertainty results}
\noindent The uncertainty analysis answers a different question from the main comparison. It does not ask which model wins the three split comparison. Instead, it asks whether the uncertainty output of a separate uncertainty enabled UPert run produces a useful reliability signal. In that analysis, higher predicted uncertainty is usually associated with larger absolute error, and this relationship is strongest in cold cell and weaker in cold drug target. The prediction band is shown as $\mu \pm 2\sigma$. Under a Gaussian view, this can be read as a rough 95\% interval. In the updated results, coverage is close to that level in warm and cold cell, but it drops clearly in cold drug target, and the test NLL is also higher there rather than catastrophically worse. This means the uncertainty output is useful as an error ranking signal, but its calibration is not equally strong in all three splits. A more complete evaluation would combine coverage with test negative log likelihood and residual diagnostics.

\subsection{Data efficiency results}
\noindent The warm split data efficiency analysis answers another separate question. It examines whether the graph based model stays useful when the training budget is reduced. In the warm split budget analysis, UPert remains strong when the amount of training data is reduced, which suggests that the biological graph may help when data are limited in this setting. In this kind of biology work, repeated measurements are expensive, and many drug cell combinations still have only limited data. A model that stays useful with less data can be more useful than a model that performs well only when data are abundant.

\subsection{Attention case studies}
\noindent The case studies give a detailed but limited view of attention. When a prediction is accurate, the model often gives high weights to a smaller and easier to read set of graph edges, and some of these edges are consistent with known drug targets or later response genes. When a prediction is weak, large edge weights can still appear, but they are harder to summarize in a useful way. This means attention can be useful as a model clue, but not as direct biological proof. A high attention edge does not prove that the interaction caused the response in the cell.

\section{Limitations and Future Work}
\noindent A major limitation of the model is that the biological graph is fixed, while real cell responses change across settings. The same regulatory link may not be equally important in every cell type or every baseline state. Because the graph structure does not change across samples, the model can miss cell specific biology. This is one likely reason why cold cell remains difficult. The framework captures general biological structure, but it does not adapt the graph itself to different cell conditions.

\noindent Another limitation comes from the input information. The model uses known drug targets because they are simple and biologically meaningful. But drug target annotations are incomplete, and some compounds act through secondary or poorly characterized effects. In such cases, even a well designed graph model may receive an incomplete starting signal. Some prediction failures may come from limited prior knowledge, not only from model weakness.

\noindent The split design also has an important limitation. In the cold drug target setting, the train and test drugs are different compounds, but different drugs can still share part of their target profile. Cold drug target therefore does not fully remove overlap in drug targets. The split is still useful for testing transfer to unseen compounds, but it is weaker than a fully target disjoint evaluation.

\noindent The data efficiency setup also has a limitation. In that experiment, the reduced training sets still keep at least one sample for each observed drug cell pair whenever the setting is positive. For that reason, the analysis does not test what happens when an entire pair is missing from training. It should therefore be read as a repeated measurement data efficiency test rather than as a new unseen pair evaluation.

\noindent The study is also limited by the scope of the data. The main experiments use the 978 landmark genes in LINCS L1000. This keeps the setup manageable and close to the assay design, but it also means that large parts of the transcriptome are not modeled directly. The landmark setting is a practical compromise. It reduces computational cost, but it removes many genes that could help explain longer range responses. Some missing information may be partly reconstructed through correlated landmark patterns, but this remains an indirect view of the full transcriptome. In addition, the dataset contains a limited set of cell lines, many of which are cancer related. The conclusions are strongest for this benchmark setting and should not be taken as direct evidence that the same performance will hold in all biological systems. Extending the analysis to a larger gene set, or to an external transcriptome dataset, would help test how much of the present gain depends on the landmark setting itself.

\noindent Another limitation is explanation. High attention weights do not show how biology works by themselves. They only show which graph edges the model used more strongly when making a prediction. For this reason, the attention results should be treated as clues for future lab experiments, not as proof of how a drug works. This is especially important when the prediction itself is weak, because strong weights can still appear in cases that are difficult to explain.

\noindent The uncertainty output has limitations as well. UPert predicts a Gaussian variance term for each gene, and this is useful for ranking harder and easier cases. However, good ranking does not automatically mean that the uncertainty is fully correct. The thesis does not strictly prove that the conditional target distribution is Gaussian. Instead, the Gaussian likelihood is used as a practical probabilistic regression assumption. A well calibrated model should not only assign larger uncertainty to harder cases. It should also give good likelihood values, produce prediction intervals with the expected coverage, and show reasonable residual behaviour after standardization. The updated results illustrate both sides of this point. Warm and cold cell show reasonable coverage, but cold drug target still has poor NLL and under coverage. The present thesis therefore shows useful uncertainty signals, but it does not yet establish full uncertainty calibration.

\noindent The comparison with GSNN also has an important limitation. GSNN is a relevant graph based baseline, but it is not matched to UPert in every modeling choice. In particular, it does not use the same combined loss function and it does not predict a gene wise uncertainty term. For this reason, the comparison should be read mainly as a benchmark comparison between two graph based approaches under the same data and split settings, not as a fully controlled ablation that isolates only the message passing rule.

\noindent The experimental comparison also has practical limits. The main models were trained only once without repeated runs under different random seeds, because full repetition across all models and all splits would have exceeded the available time and hardware budget. As a result, the reported numbers cannot be presented with a mean and standard deviation across runs, and some performance differences between models may be partly affected by training stochasticity rather than by model design alone. In addition, a dedicated validation split was not used for broad hyperparameter search. Some hyperparameter choices were inherited from earlier work and some were adjusted only within the memory and runtime limits of the available hardware. This also applies to the weight of the PCC loss term. In the reported implementation, $\lambda_{\mathrm{pcc}}$ was set empirically to 5, and only small preliminary tests with nearby values were used to judge whether this gave a reasonable balance between the likelihood term and the profile shape term. A broader sensitivity analysis was not carried out. For this reason, the reported numbers should be read as strong benchmark evidence, but not as the final fully tuned upper bound for each method.

\noindent These limitations suggest several directions for future work. One direction would be to let the graph change with the sample, so that the connections can depend on the specific cell line or baseline state. Another direction would be to improve the drug representation, for example by combining target annotations with other information when targets are incomplete. Better uncertainty calibration would also be useful, so that the uncertainty values are easier to use in later decisions.

\noindent A further direction is stronger biological validation. The current case studies show that some high weight edges look reasonable and some do not. A next step would be to compare these edges in a more systematic way with known pathways or with later experiments. That would help separate cases where the model is using biologically meaningful structure from cases where it is only using broad response signals.

\section{Ethical Considerations}
\noindent This work uses public perturbation transcriptomics data and does not involve direct experiments on human participants or animals. Even so, several ethical issues remain relevant. Predictions of drug response can appear more certain and more general than they really are. For that reason, the model should not be used as a clinical decision system or as proof that a drug will be effective in patients. The present results come from cell line benchmark data, and they should be interpreted within that scope.

\noindent Another ethical issue concerns bias in the data. The LINCS collection contains a limited set of cell lines and experimental conditions. Many cell lines are cancer related, and some biological contexts are represented much better than others. A model trained on such data may perform unevenly across biological settings that are not well covered by the benchmark. This limitation should be acknowledged when presenting the method or discussing any possible downstream use.

\noindent Interpretation raises another ethical issue. Attention maps and graph edges can look persuasive, which may encourage users to read them as proof of biological mechanism. That would be misleading. The model can provide hypotheses and useful clues, but these outputs still need external validation. This limitation should be stated clearly to avoid overclaiming biological insight.
